## 这 12.9 加元买的是 IP 属性

原生 IP 的实际用途集中在三块：跨境平台的账号注册与登录环境、需要区域归属的服务开通、以及支付通道对 IP 归属地的风控判断。第三方测评对这台机器的 IP 测试结论是“确实原生 IP，能够解锁多种服务”，并把它归到“适合跨境外贸业务需求用户”。这些是测评方的判断，不是官方承诺，但对判断方向够用了。

关键在于这个能力和低价方案之间的差距。以 RackNerd 多伦多为例，它的资料里没有承诺加拿大原生 IP，反而明确提醒“没有原生加拿大 IPv6 保证”，想要用 IP 解锁流媒体的人应该先开工单问清当前批次的 IP 属性。这就形成了一个很实际的分岔：

- 你只是要一台在加拿大的服务器跑网站、跑脚本、做备份，IP 是广播还是原生对你没有影响，那原生 IP 的溢价就是白花的。
- 你的业务会因为 IP 归属被卡（注册失败、验证不通过、区域服务打不开），那省下的钱最后会以别的方式还回去。

## 三网延迟 246ms，这个数字该怎么读

第三方测评的测试结果：测评者本地 Ping 平均 **215ms**，基本无丢包；全国三网平均 **246ms**，其中电信 237ms、联通 251ms、移动 254ms，港澳台及东南亚方向 210ms。全球近 100 个节点的稳定性测试“基本都没有丢包”。

这个水平对加拿大节点属于正常范围，不算差。但线路定性必须说清楚：**非优化线路**，三网去程都是从国内出口后经美国一路北上到多伦多，再进密西沙加。

- 电信：广州出口，经圣何塞、旧金山、丹佛、奥马哈、芝加哥、克利夫兰、多伦多，走电信骨干网
- 联通：上海出口，同一路径，走 **AS4837**
- 移动：上海出口，同一路径，走 **CMI 骨干网**

没有 CN2、没有 GIA，绕的是美国中西部。这意味着两件事：一是延迟下限就在 230ms 上下，不会再低；二是高峰期表现取决于这段美国骨干的拥塞情况，测评当时稳定，不代表你用的每一天都稳定。

对延迟敏感的实时业务（语音、游戏、远程桌面）在 240ms 以上会明显难受，这类需求不该选加拿大节点，选美西更合理。

## 200Mbps 是共享的，1TB 流量够不够

两个口径容易被误读，提前说清。

**共享带宽不等于独享端口。** 200Mbps 是共享口径，同物理机上的邻居跑满时，你的实际可用速率会低于这个数。另外，端口标称值和跨境实际吞吐是两回事：从国内拉这台机器的数据，能跑多少取决于上面那条经美国中转的线路，测评里没有给出带宽实测数据，我也不会替它编一个。需要跑大流量传输的，先拿测试数据说话。

**1TB 月流量大约等于每天 33GB。** 一个日均几千 PV 的文字博客、一个企业展示站，一个月通常用不到 100GB，1TB 绰绰有余。但如果是图片站、视频分发、做镜像或者跑采集回传，1TB 会很快见底。WePC 其他产品线有“超流量后限速”的做法，加拿大这档超额后的具体处理方式官网没有核验到，下单前值得问一句。
